# RUSHI.BUILD — Personal Portfolio

Personal portfolio of **Rushi (Dabhi Rushiraj Jayeshbhai)** — 1st-year B.Tech CSE (AI & ML) student at Gyanmanjari Innovative University (Bhavnagar), building Agentic AI, Civic-Tech, and Full-Stack products.

## Highlights
- **Zero-framework static architecture:** Built in pure semantic HTML5, modern CSS3, and vanilla JavaScript.
- **Interactive WebGL2 3D Particle Portrait:** Custom 29k+ surface-point cloud with cursor parting, click ripples, scroll-linked rotation, drag-to-orbit, and photo cutout toggle (plus Canvas2D fallback).
- **Signal Emerald & Carbon Noir Editorial Design:** Custom typography reveal choreography, horizontal continuous showcase reel (with WCAG Pause/Play), filterable project cards, native top-layer `<dialog>` case-study & credential modals, interactive K.A.I.R.O.S. dot-wave terminal, and accessible contact validation.
