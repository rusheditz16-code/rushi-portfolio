# Rushi Portfolio

Personal portfolio of **Rushi (Dabhi Rushiraj Jayeshbhai)**, B.Tech CSE (AI & ML) student at Gyanmanjari Innovative University, Bhavnagar.

Live site: https://rushi16.vercel.app

## Stack
- HTML5, CSS3, and vanilla JavaScript (no frameworks)
- WebGL2 interactive 3D portrait + Canvas2D wave terminal
- Hosted on Vercel

## Run Locally
Open `index.html` directly in a browser, or serve locally:
```bash
python -m http.server 8765
```
